# Sources biologiques et provenance

Le concept de transformer V888 intégralement en booléen et d'en expérimenter le calcul relève de **l'initiative du porteur du projet Memorithm**. Les données biologiques constituent une source scientifique indépendante, dont les auteurs doivent être crédités conformément aux licences.

Références scientifiques déclarées pour vérification avant acquisition :

- Bates, A. S., Phelps, J. S., Kim, M. et collaborateurs (2026). *Distributed control circuits across a brain-and-cord connectome*. Nature. DOI : https://doi.org/10.1038/s41586-026-10735-w
- Consortium BANC/FlyWire, jeu de données BANC v888 : https://doi.org/10.7910/DVN/7WTH1N
- Documentation : https://github.com/htem/BANC-project

La version visée est **V888**. Vérifier dans les métadonnées d'origine les dates, périmètres et licences propres à chaque fichier au moment de son téléchargement. Ne jamais confondre l'inventaire d'un sous-ensemble avec la totalité du jeu de données.

Pour chaque fichier source : URL stable, version de matérialisation, nom et taille, SHA-256, date de récupération, licence, description des colonnes et unité. Aucune donnée brute n'est livrée dans cette initialisation.
